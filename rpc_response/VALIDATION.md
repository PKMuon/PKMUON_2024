# 首版验证记录（2026-10-19）

后续2026-10-20验证：新增理想空间多位置模型；3σ/5σ/10σ全量检查397659个窗口的时间边界、轨迹数、段数与电离沉积守恒，且输出中心两两距离大于所选门限。5σ输出408043个位置，9547窗多位置。CTest覆盖远轨迹拆分、近轨迹合并及重心、时间分组、层隔离、连通近轨迹链；插值测试覆盖完整事例相关性、无效电荷保留、能量越界拒绝、留出点排除。实际Heed新种子五个中间能量用于交叉验证；详细结果见 `results/comparison_20261020/spatial_interpolation/spatial_interpolation_report.html`。下述10 ns及多轨迹拒绝计数仅为首版历史验证。

范围：用户确认的“参考库＋坐标基线”，不是经效率/电荷谱标定的完整响应。

## 环境与构建

复用本机 VirtualBox Ubuntu 的 ubuntu-vm SSH 连接及共享目录 ~/muon。
Ubuntu GCC 13.3.0、ROOT 6.34.04、Geant4 11.1.2；Garfield++使用虚拟机原有安装。
响应工具全部编译通过；Geant4在独立build-rpc目录编译通过；内核CTest通过，脚本语法检查通过。

## 输入与模型

纯R-134a、298.15 K、760 Torr；2 mm气隙；用户确认低计数率稳态忽略玻璃压降，因此气隙电压10,100 V，场强50.5 kV/cm。
Magboltz扫描10、20、30、40、50、60 kV/cm，每点ncoll=1（10^7碰撞）；50.5 kV/cm由表内插值获得。该表为探索性统计，未作输运参数精密误差评估。

## 验证结果

| 检查 | 结果 |
|---|---|
| 线性出生/死亡过程 | 纯出生、纯附着、临界、净附着均值通过 |
| 理想平板Ramo积分 | 无放大解析值与放大平均积分检查通过 |
| 空间展宽内核 | 120000次：X=0.748386 mm，Y=0.749501 mm |
| 名义延迟线 | 每方向8×40 ns，合计320 ns；无噪声往返通过 |
| ROOT坐标全链路 | 20000次：X=0.754403 mm，Y=0.748392 mm，符合输入0.749 mm的统计预期 |
| Geant4气隙记录 | 200个事例、4层、1902个气隙步，含1057个次级轨迹步 |
| 实际坐标基线 | 800条层读出记录：708条有效坐标，92条多轨迹歧义（NaN坐标） |
| 单电子参考库 | 0—2 mm，间隔0.05 mm，41个深度，每深度1000样本 |
| 线性模型保护 | 15469/41000样本越界，均保留valid=false，未截断或重抽 |

上述708/800不是探测效率；92条歧义也不是测得的双命中损失。它们来自此基准及保守多轨迹策略（包括次级粒子）。实际坐标基线使用演示时间窗10 ns，未标定。

参考库的线性模型上限为10^7电子，数值积分步长0.01 mm，随机种子20261018。上限不是物理饱和电荷。深度1 mm时0/1000越界；1.5 mm时967/1000越界；2 mm时985/1000越界。因此长漂移段不能用该线性库预测真实幅度或效率，后续必须考虑饱和/空间电荷。

## 耗时示例

虚拟机内100万次已加载参考库的缓存抽样耗时0.0224 s；不含文件加载、Geant4输运、雪崩制表或电子学。
41000条单电子参考样本生成耗时1.55 s；20000条合成坐标事件的ROOT读写与数字化约0.14—0.16 s。
Magboltz六场点扫描耗时为分钟级，是本轮主要离线成本；未记录精确的端到端计时，不提供推算加速倍数。
