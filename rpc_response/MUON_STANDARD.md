# 缪子标准工作点及图表

本次标准点：1 GeV动能、垂直入射mu-，10000事例，随机种子20261019；X/Y穿越位置在[-100,100] mm均匀分布。不是宇宙线能谱抽样，也未覆盖其他能量和入射角。

气体与场条件沿用已确认值：纯R-134a、298.15 K、760 Torr、2 mm气隙、50.5 kV/cm。
Heed独立生成电离与δ电子级联；现有线性单电子库被逐电子查询。该样本不与Geant4电离叠加。

| 统计量 | 结果 |
|---|---:|
| 初级电离簇平均数 | 15.7064 /muon |
| 气隙内电子平均数 / 中位数 | 36.9045 / 27 |
| Heed能量转移平均数 / 中位数 | 1.23428 / 0.77787 keV |
| 最晚名义电子到达时间平均数 | 17.7276 ns |
| X坐标残差样本标准差 | 0.75574 mm |
| Y坐标残差样本标准差 | 0.74929 mm |
| 时间和差样本标准差 | 2.45394 ns |
| 参考库单电子查询无效比例 | 38.8446% |
| 至少一个电子查询无效的缪子比例 | 99.76% |

能量转移不是严格的局部能量沉积；可能存在逃逸次级粒子。名义电子到达时间为出生时间加漂移距离/速度，未包含扩散与阈值判时。

坐标残差由输入0.749 mm总sigma及假定独立端点抖动生成，是经验模型检查而非独立分辨率预测。绝对计时、X/Y共模时间误差尚未标定，不能直接把时间和差宽度与实验不加区分地比较。

99.76%是线性模型保护触发比例，不是探测无效率，也不等于测得的streamer比例。任何一个电子越界，整条缪子的总线性电荷记NaN；未将无效项记为0，也未重抽或只累加有效部分。因此目前不能画出物理可信的完整缪子电荷谱。

图表目录：`results/muon_1GeV_normal_v1_plots/`。

* 01_muon_ionization：簇数、电子数、能量转移、电子深度、名义时间及越界比例。
* 02_linear_reference：深度相关有效范围、有效单电子电荷条件分布、名义漂移时间及线性增益。
* 03_delay_coordinate：X/Y残差、残差相关性、名义位置—时间差关系、时间和差。
* 04_gas_transport：漂移速度、Townsend/附着/有效增益系数、扩散系数随场强变化。
* muon_standard_distributions.pdf：以上四页合并PDF；各页另存矢量PDF和PNG。
* summary.json：全部关键统计量。

ROOT数据：`results/muon_1GeV_normal_v1.root`，树名muonStandard；同前缀CSV保留逐事例、逐簇和逐电子数据。
样本生成耗时约1.93 s（已生成的气体表与单电子库载入后）；固定种子重跑前100事例，所有导出事例字段一致。绘图检查了数据数量、深度范围、无效电荷NaN标志及残差宽度；四页图已逐页查看。
