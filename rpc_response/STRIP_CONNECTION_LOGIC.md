# 当前简化范围：条带通道与延迟线连接

2026-10-31新增：`scripts/strip_charge_sharing.py`按高斯电荷轮廓在PCB实际条带中心的几何归属单元内积分，生成同一信号在相邻多条带的份额。演示入口 `scripts/plot_shared_strip_four_ends.py` 已运行，图和数据见 `../deliverables/Shared_Strip_Four_Ends_20261031/`。4 mm FWHM为R015启发的预设，高斯形状及几何归属都是近似，不是实际权重场。

用户2026-10-30明确缩减范围：目前只需要电路连接逻辑，将原整板读出拆为条带读出，不展开材料扫描和三维权重场。此前材料研究保留为历史，不作为运行前置条件。

1. 每个读出方向有81个条带网络。X方向沿用PCB名称1…81，Y方向Y1…Y81。连接同一网络的Y铜块属于同一条带通道，不能每块各输出一次信号。
2. 条带k（从0计数）连接到抽头k；到网络1端的标称延迟为4k ns，到网络81端为4(80−k) ns。两方向分别形成320 ns链。没有从真值位置直接平移一份整板波形。
3. 输入每条带自身的电流i_k(t)，两端输出分别为 `I_1(t)=sum f*i_k(t−4k)` 和 `I_81(t)=sum (1−f)*i_k(t−4(80−k))`。当前简化为对称分流f=1/2、无损传播。f不是PCB网络可唯一确定的实测幅度。
4. 同条带的多个粒子先叠加，或逐个贡献后在端点相加，两者在线性模型下等价。不同条带保留不同的传播延迟。因此同窗远分离命中可产生多脉冲，不再先合成整板重心。
5. 输出四个端点电流，单位nA。尚不根据波形自动执行阈值判时和多端配对，也不宣称得到已标定电压。

程序：`scripts/strip_delay_readout.py`。

输入CSV列：`net,t0_ns,t1_ns,current_nA`。时间为绝对时间，电流保留符号，每行是一个恒定电流时间段。条带外的辅助网络、GND输入会报错，不强行接到任意抽头。

这一简化模块负责连接、延迟与求和。上游必须先形成每条带信号；若把原平板Ramo信号按位置归入条带，应标为几何归属近似。条带间电荷共享、真实条带权重场均未因该连接模块而自动计算完成。不能将同一总电荷不加说明地复制到81根条带。
